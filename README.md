# GASS Booking

General Affair Services System (GASS) mengelola peminjaman ruang rapat dan kendaraan, approval berjenjang, master data, dashboard operasional, serta notifikasi email.

## Mulai Bekerja

1. Baca [`AGENTS.md`](AGENTS.md) untuk konteks dan aturan engineering utama.
2. Baca [`docs/PROJECT_HANDOVER.md`](docs/PROJECT_HANDOVER.md) untuk status implementasi terkini.
3. Gunakan dokumen domain yang relevan sebelum mengubah kode.

## Dokumentasi

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md): arsitektur aplikasi dan batas modul.
- [`docs/BUSINESS_RULES.md`](docs/BUSINESS_RULES.md): role, approval, booking, dan lifecycle transaksi.
- [`docs/DATABASE.md`](docs/DATABASE.md): PostgreSQL, schema, tabel, dan migrasi.
- [`docs/EMAIL_WORKFLOWS.md`](docs/EMAIL_WORKFLOWS.md): event dan template email Resend.
- [`docs/WHATSAPP_NOTIFICATIONS.md`](docs/WHATSAPP_NOTIFICATIONS.md): integrasi trial WhatsApp Gateway EVA.
- [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md): validasi, release, rollback, dan pemeriksaan produksi.
- [`docs/decisions`](docs/decisions): keputusan arsitektur yang telah diterima.

`memory/PRD.md` adalah artefak historis dan bukan sumber kebenaran untuk kondisi aplikasi saat ini.
